 Agence de Voyage Haïti - Site Vitrine

Bienvenue sur le dépôt du site vitrine officiel de notre agence de voyage en Haïti. Ce site a pour objectif de promouvoir le tourisme local, de présenter nos circuits touristiques et de faciliter la prise de contact avec nos clients.

 Fonctionnalités
Vitrine attractive : Présentation des plus beaux sites touristiques d'Haïti (Labadee, Citadelle Laferrière, Saut-d'Eau, etc.).
Galerie interactive : Immersion visuelle grâce à des photos et vidéos de haute qualité.
Formulaire de contact : Permet aux utilisateurs de demander un devis ou des informations.
Design adaptatif (Responsive) : Optimisé pour les smartphones, tablettes et ordinateurs.

## 📁 Structure du Projet
Le projet est organisé de la manière suivante :

├── index.html          # Page d'accueil (présentation, offres phares)
├── apropos.html        # Histoire de l'agence, mission et équipe
├── galerie.html        # Photos et vidéos des destinations
├── contact.html        # Formulaire de contact et coordonnées (Map, réseaux sociaux)
├── css/
│   └── style.css       # Feuilles de style pour la mise en forme et le design
├── js/
│   └── main.js         # Scripts pour les animations et la validation du formulaire
└── assets/
    ├── images/         # Photos des paysages, hôtels et circuits
    └── videos/         # Clips promotionnels et arrière-plans animés

 Technologies Utilisées
HTML5 : Structure sémantique des pages.
CSS3 : Design moderne, Grid, Flexbox et animations.
JavaScript (Vanilla) : Gestion du menu mobile et interactions de la galerie.

  Installation et Lancement Local
1. Cloner le dépôt:
   ```bash
   git clone https://github.com
   ```
2. Naviguer dans le dossier :
   ```bash
   cd agence-voyage-haiti
   ```
3. Ouvrir le projet :
   Double-cliquez sur le fichier `index.html` pour l'ouvrir directement dans votre navigateur internet.
